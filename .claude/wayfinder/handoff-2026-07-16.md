### ❌ Items 3–6 — Not Started (start here next session)

**Item 3 — LLM unknown merchant categorization**
Ticket 004 decided: "LLM resolves unknown merchants." Spec §6 implements: "dump to uncategorized queue, flag for user review." These contradict. Resolution: async LLM categorization job that runs *after* sync completes (preserves the "LLM never runs on sync" principle from §7). Read spec §6 and §7 before starting. Update spec with the resolved design.

**Item 4 — Tangerine data lag**
Tangerine transactions are 5–9 days stale even on healthy connections. The LLM system prompt (spec §8) has no awareness of this. Two changes needed:
1. Add Tangerine staleness context to the LLM system prompt so it doesn't make false-precision budget recommendations on stale data.
2. Add a user-facing staleness indicator in the Tangerine connection row in Settings.

**Item 5 — Prompt cache TTL cost model**
Anthropic's prompt cache TTL dropped from 60 min to 5 min in early 2026. For a personal finance app with sessions hours apart, the cache is almost always cold. The spec's LLM design (§8) doesn't account for this. Fix: add Batch API nightly analysis (50% discount) for the scheduled 2am analysis run. Synchronous calls remain for on-demand/alert-triggered sessions. This corrects the cost architecture and improves perceived performance (cards pre-generated when user opens the app in the morning).

**Item 6 — Scotiabank fragility**
Plaid's Scotiabank connection is credential/scraping-based with 2–4 expected auth breaks/year. At scale this compounds into support overhead and churn. Two additions to spec needed:
1. Explicit post-launch KPI: log each `ITEM_LOGIN_REQUIRED` event by institution; if Scotiabank relink frequency exceeds 4x/year/user on average, treat as a churn risk signal.
2. CDBA (Consumer-Driven Banking Act) Phase 1 migration: Bill C-15 received Royal Assent March 2026, draft regs June 2026. Phase 1 read access targeted H2 2027. Schedule a Q3 2027 review to migrate Scotiabank (and potentially Tangerine) to a CDBA-compliant aggregator. The `BankSyncProvider` abstraction in the spec is designed to make this a contained swap.
